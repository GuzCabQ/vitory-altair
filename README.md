# vitory-altair

> Portal Web de VITORY — Dashboard para organizadores de torneos de Tocho Bandera

## Stack
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- TanStack Query v5

## Setup

1. Clonar: `git clone git@github.com:GuzCabQ/vitory-altair.git`
2. Dependencias: `npm install`
3. Configurar: `cp .env.example .env.local`
4. Ejecutar: `npm run dev`
5. Abrir: http://localhost:3000
